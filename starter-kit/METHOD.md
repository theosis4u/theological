# Working method

Start from the public [method template](../guides/ai-theology-method-template.md) (in this repo template it is linked relatively; replace with the full URL once copied: `https://github.com/theosis4u/theological/blob/main/guides/ai-theology-method-template.md`).

1. Copy the template's sections 1–9 below this line.
2. Fill in the placeholders: `<your tradition>`, `<default translation>`, `<comparison translations>`, `<your tradition's study resources>`, `<preferred modern scholars>`, `<other traditions' primary texts>`.
3. Paste the "your tradition first" text from the matching [tradition pack](../traditions/) into section 4, and edit it so it says what you actually hold.
4. Adjust lengths in section 2 to taste.

# Debate or thread analysis

## Prompt

```text
Request type: debate / thread analysis (600–1,200 words, plus a reply draft under <N> characters).
Post or argument: <paste text or link>
Follow METHOD.md.
1. Quote exactly what the post claims.
2. State what the poster's own tradition's documents actually say on the point, cited by section.
3. Show where the argument holds and where it fails. Name a fallacy only if the argument depends on it.
4. Note any point where my side would make the mirror-image mistake.
5. Draft a reply in a <gentle / direct> tone. I will post it myself.
```

## Example

```text
Request type: debate / thread analysis (600-1,200 words, plus a reply under 280 characters).
Post: "John 1:5 in the KJV says the darkness 'comprehended it not,' so the verse is about people failing to understand Jesus, and modern Bibles changed it to 'overcome.'"
Follow METHOD.md. [steps 1-5 as above, gentle tone]
```

A good answer would explain that the Greek verb (*katalambanō*, "to seize, grasp") can mean grasping with the mind or seizing to overpower, that translations differ for that reason, and that the KJV's own margin and other early English versions should be checked rather than assumed.

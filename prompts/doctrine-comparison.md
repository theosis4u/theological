# Doctrine comparison

## Prompt

```text
Request type: doctrine comparison (1,000–1,800 words).
Question: <doctrine question>
Traditions: <your tradition> and <tradition B> (and <tradition C> if relevant).
Follow METHOD.md.
1. State the question plainly.
2. Give <your tradition>'s position from its own standards.
3. Give each other tradition in its own primary-text words, cited by section.
4. Separate real differences from differences in vocabulary.
5. List the key Scripture texts each side relies on.
6. Apply the test: set the sentence from each tradition's document that carries the doctrine next to the passage it seems not to fit, and ask whether the tension is resolved or only renamed.
7. Name a fallacy only if an argument depends on it.
8. State the remaining tension honestly, including weaknesses on my side.
```

## Example

```text
Request type: doctrine comparison (1,000–1,800 words).
Question: What does John 1:1 teach about the relation of the Word to God, and how do the creeds express it?
Traditions: my tradition and one other tradition I engage often.
Follow METHOD.md. [steps 1-8 as above]
```

This example uses a topic on which most traditions agree, which makes it a good first test: a fair answer should find mostly differences in vocabulary and emphasis, and say so.

# Class or Logos note

## Prompt

```text
Request type: class / Logos note (1,500–2,500 words; fits one Logos note).
Session: <class or study name>, <date>, <passage or topic>
Questions to answer: <paste the questions>
Follow METHOD.md.
- Reprint each question in bold, then answer it in short paragraphs with sources named inline.
- Quote verses inline. Put long quotes from library resources in indented blocks with their citation and ref.ly link (I will paste these from Logos; leave a <ref.ly link from your Logos copy> placeholder where needed).
- No tables in the final note (Logos notes cannot hold them); use lists.
- Write Markdown with a front-matter title; I will convert it with tools/md_to_logos_html.py.
```

## Example

```text
Request type: class / Logos note (1,500-2,500 words).
Session: Gospel of John class, week 1, John 1:1-5
Questions to answer:
1. What does "In the beginning" echo, and why does it matter?
2. What does it mean that the Word was "with God" and "was God"?
3. How should we read "the darkness comprehended it not" (v. 5)?
Follow METHOD.md. [rules as above]
```

# Prompt Library

One prompt per request type from the [method template](../guides/ai-theology-method-template.md). Each file has a reusable prompt with `<placeholders>` and a filled-in example on a neutral passage. Give your assistant your `METHOD.md` first, then the prompt.

| Request type | File | Default length |
|---|---|---|
| Quick question | [quick-question.md](quick-question.md) | 150–400 words |
| Passage study | [passage-study.md](passage-study.md) | 600–1,200 words |
| Doctrine comparison | [doctrine-comparison.md](doctrine-comparison.md) | 1,000–1,800 words |
| Debate or thread analysis | [debate-thread-analysis.md](debate-thread-analysis.md) | 600–1,200 words + reply draft |
| Class or Logos note | [class-or-logos-note.md](class-or-logos-note.md) | 1,500–2,500 words |

For every request type: write Bible references in full (book, chapter, and verse, e.g. "John 3:16", not "v. 16") so verse pop-ups and Logos auto-linking work, and link them to Biblia.com when sharing.

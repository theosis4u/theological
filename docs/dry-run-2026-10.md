## Method

Three fictional newcomers followed [START-HERE](../START-HERE.md) literally, step by step, with no outside help. For each, we noted where the instructions stalled, assumed Logos or Christianity, or were unclear, and then fixed the docs. The personas are invented; no real users were involved.

## Persona 1: a Protestant coworker with only Microsoft Copilot, no Logos

### Walk-through

1. Pasted the quick prompt into the free Copilot app. It could not read the GitHub repo or open a ZIP.
2. Fell back to "upload or paste just these files". The list omitted START-HERE itself, so the assistant was asked to follow "Instructions for the AI assistant" it never received.
3. The interview went smoothly for a Christian, but the step "Produce a filled-in PROFILE.md and METHOD.md" assumed the assistant can create files.
4. "What to do next" pointed to the setup checklist "especially the Logos citation settings", and the Copilot guide assumed Logos throughout.
5. Creating the private repo assumed git on the command line.

### Fixes

- The fallback file list now starts with START-HERE and includes the starter-kit `PROFILE.md` and `METHOD.md`, with a note on uploading one by one or pasting from **Raw**.
- The onboarding prompt tells the assistant to output each file in a code block if it can't create files.
- The setup checklist says to skip Logos sections if you don't use Logos; the [Copilot guide](../guides/copilot-workflow.md) has a "No Logos?" note.
- START-HERE and the starter kit explain creating the repo on github.com with **Add file > Upload files**.

## Persona 2: a Sunni Muslim

### Walk-through

1. The onboarding prompt began "I'm setting up a Bible study workflow", which does not fit.
2. Interview question 3 asked for "My default Bible translation".
3. "Free-resource mode" pointed only to the free-resources guide, whose tradition lists are Christian, and offered to build a free Logos library.
4. The example exchange offered only Christian traditions as the first question.
5. The "What to connect" table listed only Bible sites.
6. The Islam pack itself, with Sunni madhhabs and free sources, worked well, as did the opt-in [Quran pop-ups](../examples/quran-popup-demo.md).

### Fixes

- The prompt now says "a study workflow (for the Bible, my own tradition's texts, or comparing worldviews)".
- Question 3 asks for "main texts and translations", with examples for other scriptures and for secular views.
- Free-resource mode is the default and points first to the user's pack's "Free online sources"; the Logos offer applies only to Bible study.
- The example asks about families and branches; the connect table now names Quran.com, Sefaria, SuttaCentral, and SikhiToTheMax/BaniDB as free scripture sites.

## Persona 3: an atheist skeptic

### Walk-through

1. Same "Bible study" and "Bible translation" wording problems as persona 2.
2. The stance setting fit well: committed advocacy for a secular view, with the fallacy review on both sides.
3. The secular pack gave clear branches (atheist, agnostic, humanist, naturalist, skeptic) and sources.
4. Unclear what "translation" means without a scripture.

### Fixes

- Question 3 now asks secular users for "the key authors or works I rely on".
- The quick-start callout lists "your main texts and translations (a Bible, the Quran, the Pali Canon, or none)".

## Remaining open items

- The main how-to and the Logos-note tools are, by design, Logos-centred; non-Logos users can skip them.
- The free-resources guide's tradition lists are still Christian; other traditions' free sources live in their packs.
- A real newcomer from each group should still try the flow and report problems with the [issue templates](https://github.com/theosis4u/theological/issues/new/choose).
